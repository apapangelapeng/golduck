    Exact scorer arithmetic

    Submission score calculation

    Every submitted active level is scored independently, then the Level 3 and Level 4 totals are added. Values below update with the selected solution and seed.

    Formula used for every level

    P = 900,000 + R + D + GPerformance score

    R = 100,000 ÷ (max(runs, 1) + 1) Run bonus · maximum 50,000; 0 and 1 run both receive it

    D = 25,000 × (1 − d)Density bonus

    G = 25,000 × (1 − g)Generation bonus

    K = known-correct gate × known bits ÷ 64Known weight

    Q = 0.5 × (0.4 × right − 0.6 × wrong) ÷ 64Guess weight

    Run count and performance score

    r = number of completed runs for this level R = 100,000 ÷ (max(r, 1) + 1) P = 900,000 + R + D + G

    R is at most 50,000. Zero runs and one run both receive 50,000; for r ≥ 1, each additional run lowers the bonus. D and G are defined below.

    How density ratio d is calculated

    clamp[0, 1](x) = min(1, max(0, x)) di = clamp[0, 1](ln(ni + 1) ÷ ln(A + 1)) d = max(d1, …, druns) = clamp[0, 1](ln(Nmax + 1) ÷ ln(A + 1)) D = 25,000 × (1 − d)

    ni is the number of live cells in run i's contestant input at generation zero, and A is the full contestant rectangle width × height. Nmax is the largest such count. With no runs, d = 0. The scorer uses the largest single run—not total or average cells, RLE dimensions, or the population after evolution.

    How max generation ratio g is calculated

    gi = clamp[0, 1](ln(ti + 1) ÷ ln(Tcap + 1)) g = max(g1, …, gruns) = clamp[0, 1](ln(Tmax + 1) ÷ ln(Tcap + 1)) G = 25,000 × (1 − g)

    ti is run i's requested generations, Tmax is the largest request, and Tcap is that level's maximum allowed generations. With no runs, g = 0; any run at the cap makes g = 1. Totals and averages are ignored.

    Submission bits and answer weights

    E = V xor S cK = 1 if MK ≠ 0 and (E and MK) = 0; otherwise 0 k = popcount(MK) qright = popcount((not E) and MQ) qwrong = popcount(E and MQ) K = cK × k ÷ 64 Q = 0.5 × (0.4 × qright − 0.6 × qwrong) ÷ 64

    S is the 64-bit secret, V is the submitted value, E marks wrong bits, MK is the known mask, and MQ is the guess mask. The known and guess masks must be disjoint. The known gate is all-or-nothing: one incorrect known bit makes all of K zero. Correct guesses add weight; incorrect guesses subtract it.

    Exact bonus, level score, and submission total

    H = 100,000 if cK = 1 and MK = 0xffffffffffffffff; otherwise 0 L = P × (K + Q) + H active total = L3 + L4

    H requires all 64 bits to be marked known and every one to be correct. Unsubmitted active levels do not contribute to the total.

    L = [900,000 + R + D + G] × [K + Q] + H Complete per-level score; the active total includes Levels 3 and 4 only.
